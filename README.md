## 🚀 Getting Started

### 💻 Technology

- Dart
- Flutter
- VSCode

### 🛠️ Build / Verification

1. Clone the repository: `git clone <url-repo>`
2. Open terminal at project workspace and run: `flutter pub get`
3. Open `/lib/main.dart`
4. Select device to use
5. Start debugging: `flutter run -d windows` (or appropriate platform)
